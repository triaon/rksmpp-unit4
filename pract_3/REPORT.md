# Задание 3: Экран поиска книг в библиотеке с debounce

Debounce — это когда мы говорим функции: «Не выполняйся сразу. Подожди, пока меня перестанут дёргать хотя бы N миллисекунд. Тогда выполнись один раз с самыми свежими данными».

Необходимо создать Android приложение.

Требования к UI:

- есть поле ввода;
- при вводе текста происходит «поиск» книг в каталоге библиотеки (по названию, автору или жанру);
- результаты отображаются в LazyColumn;
- поиск запускается не на каждый символ, а с задержкой (debounce);
- во время поиска показывается индикатор загрузки;
- предыдущий поиск автоматически отменяется, если пользователь продолжает печатать.

Требования к корутинам:

- Использовать launch/async/withContext/delay;
- Реализовать debounce (можно с помощью delay + cancel);
- Отмена предыдущей задачи при новом вводе текста (через Job.cancel());
- Всё должно работать внутри rememberCoroutineScope().

Источник данных — большой json-файл books.json в assets (90 записей реальных книг с полями: id, title, author, description, year, genre).

Пример структуры JSON файла:
```
{
  "id": 11,
  "title": "Преступление и наказание",
  "author": "Фёдор Достоевский",
  "description": "Бедный студент Раскольников совершает убийство ради идеи и мучается последствиями.",
  "year": 1866,
  "genre": "роман"
}
```
