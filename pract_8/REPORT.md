# Задание 8 (Последовательная цепочка): Подготовка скана документа к отправке

Функционал приложения:

В приложении есть скан документа (заявление) — приложение должно выполнить следующий набор действий:

1. Перевести скан в оттенки серого (Worker 1);
2. Наложить штамп с датой и подписью (Worker 2);
3. Отправить готовый документ в облако (Worker 3, имитация).

Каждый шаг зависит от предыдущего — последовательная цепочка WorkManager (`beginUniqueWork(...).then(...).then(...)`), файл после каждого шага передаётся следующему через `Data`.

Требования к реализации:

- Одна кнопка «Начать обработку и отправку»;
- Показывать текущий шаг крупным текстом («Переводим в ч/б…», «Ставим штамп…», «Отправляем…»);
- Показывать прогресс-бар (0–100% для каждого шага через `setProgress`);
- В конце — сообщение «Готово! Документ отправлен» + путь/имя файла;
- Если любой шаг упал — показать ошибку и отменить всю цепочку.

Минимальный UI:

- Text (headline) — текущий статус;
- LinearProgressIndicator (когда работает);
- Button «Начать обработку и отправку» (disabled во время работы);
- Text — результат или ошибка.
