# Задание 13 (StateFlow): Живой курс евро к рублю

Функционал приложения:

Экран показывает текущий курс евро к рублю. Курс обновляется каждые 5 секунд (имитация). Есть кнопка «Обновить сейчас» — принудительно запрашивает новый курс.

Требования:

- ViewModel с MutableStateFlow<Double> (курс);
- В init — запускается корутина, которая каждые 5 секунд эмитит случайный курс (100.0 ± 2.0);
- При нажатии кнопки — принудительно генерируется новый курс;
- UI: большой текст с курсом + стрелка вверх/вниз (зелёная/красная) при изменении + кнопка «Обновить сейчас»;
- При повороте экрана курс остаётся тем же (StateFlow сохраняет значение).
