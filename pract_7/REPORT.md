# Задание 7 (Bind service): Датчик влажности почвы, новое значение каждую секунду

Функционал приложения:

- Приложение подключается к сервису датчика;
- Сервис каждую секунду генерирует значение влажности почвы 0..100 %;
- UI показывает последнее значение;
- Кнопки «Подключиться» / «Отключиться».
