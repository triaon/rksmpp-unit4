# Задание 5 (Foreground service): Секундомер тренировки с уведомлением

Функционал приложения:

- При нажатии «Старт» запускается foreground-сервис;
- Сервис каждую секунду увеличивает счётчик (секунды тренировки);
- В уведомлении отображается: «Тренировка идёт: X секунд»;
- Приложение показывает текущее значение крупным шрифтом;

Кнопка «Стоп» останавливает сервис.
